\chapter{Dictionnaire de données}\label{sec:dictionnaire}
Pour chaque table : grain, historisation, alimentation, volumétrie, puis attributs avec type logique, nullabilité (NN non nul, N nul autorisé), rôle de clé (PK, FK $\rightarrow$ table, UK unicité) et règle de dérivation. Les types sont logiques ; leur traduction en types Hive est donnée au §\,\ref{sec:hierarchie} (\code{TIME} devient une chaîne \code{HH:mm:ss}, \code{CHAR(n)} un \code{VARCHAR(n)}) ; clés et non-nullité ne sont pas imposées par Hive et sont contrôlées avant publication (RQ-08, RQ-20, RQ-21). Les colonnes présentes dans plusieurs tables sont décrites une seule fois (tableau~\ref{tab:colcommunes}). Le dictionnaire, les schémas en étoile et le DDL HiveQL sont produits à partir d'une même description du modèle : ils ne peuvent pas diverger.
